# Cached sources

Full texts of papers and other sources, for reading. This directory is never published:
most of its contents are under copyright. Name files by their identifier (e.g.
`arxiv-2101.01234.pdf`, `doi-10.1103_xyz.pdf`).

Every source an agent reads in full is saved here first, not in a temporary directory, and
listed in `citations/consulted.md` or `citations/used.bib` (`AGENTS.md` §2, "Literature").
