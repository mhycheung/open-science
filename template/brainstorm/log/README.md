# Brainstorm log

One file per month, `brainstorm/log/YYYY-MM.md`, append only. One line per entry: the date,
the idea's id if it has one, what happened, and a pointer. When an idea graduates, record
the new project task id here. Example:

    2026-09-23 b02 — rough estimate says the effect is 10x too small; dropped. → tasks/b02/log.md
